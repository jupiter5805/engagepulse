# OULAD Data Dictionary

Key fields used in EngagePulse:

| Field | Description |
|---|---|
| id_student | Student identifier |
| code_module | University module |
| code_presentation | Course presentation |
| date_registration | Registration date relative to course start |
| date_unregistration | Withdrawal date, if applicable |
| sum_click | Recorded learning platform clicks |
| final_result | Final academic outcome |

EngagePulse uses early engagement data to predict
subsequent academic outcomes.
